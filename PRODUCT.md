# Product

## User

A developer using a Mac with a camera notch and multiple agent terminals.

## Purpose

NotchCurtain is a native macOS panel that expands on hover to show agent sessions, music, and usage limits. Optional Orca integration adds workspace details and terminal actions.

## Principles

- Keep the collapsed panel visually aligned with the physical notch.
- Reveal useful detail on hover.
- Make terminal actions clear and recoverable.
- Pair status colors with text.
- Respect reduced motion and keep UI updates responsive.
