# NotchCurtain

Небольшая нативная панель macOS вокруг выреза камеры MacBook. Она показывает сессии агентов из Orca и известных локальных CLI-процессов, доступные лимиты и управление музыкой через системный Now Playing.

## Установка

```sh
brew tap kaTrek0406/tap
brew trust kaTrek0406/tap
brew install --cask notch-curtain
```

Если macOS заблокировала локальную сборку с ad-hoc подписью, откройте приложение через Finder: **правый клик → Открыть**. Также можно снять атрибут карантина:

```sh
xattr -dr com.apple.quarantine /Applications/NotchCurtain.app
```

Требуется macOS 14+ и MacBook с физическим вырезом. Сборка только для Apple Silicon (arm64); на Mac с Intel не запускается. На дисплее без выреза панель не создаётся.

## Возможности и приватность

- Orca: локальные терминалы, статусы и доступные лимиты.
- Внешние процессы: `claude`, `codex`, `gemini`, `cursor-agent`, `aider`, `opencode`, `copilot`; рабочая папка определяется через `ps` и `lsof`.
- Лимиты Codex читаются из локального `codex app-server`; лимиты Claude показываются только если их возвращает `orca account list --json`.
- Музыка и управление воспроизведением получают через локальный мост macOS Now Playing.
- Приложение не использует `URLSession` или `URL(string:)`; сетевой HTTP-клиент в исходниках отсутствует.

Медиамост `mediaremote-adapter` обращается к приватному системному MediaRemote через Perl. Это не подходит для Mac App Store и может перестать работать после обновления macOS.

Измерения на машине разработки: около **0,17% CPU в покое** и **1,06% с фиктивным треком в свёрнутой капсуле**. Это измерения одной машины, а не гарантия производительности.

Настройки: язык, Orca и путь к CLI, музыка, лимиты, внешние сессии, экономный опрос, группировка и задержка наведения. Данные настроек хранятся локально.

## Сборка и демо

```sh
brew install cmake
swift test
./scripts/build_app.sh
```

Для скриншотов доступны полностью фиктивные данные:

```sh
NC_DEMO=1 .build/NotchCurtain.app/Contents/MacOS/NotchCurtain
```

Планируются таймер, календарь/AirPods, быстрые заметки и полка файлов. Они пока не реализованы. Подробнее: [README на английском](README.md), [CONTRIBUTING](CONTRIBUTING.md), [SECURITY](SECURITY.md).
